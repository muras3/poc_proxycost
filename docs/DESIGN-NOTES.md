# 設計上の制約（実装前のメモ）

## 1. 総額は推論。**順位も推論に対して頑健ではない**

5点 × ¥3,000・600g/点 を米国へ送る場合（1位 Neokyo ¥37,528）の内訳を確度で割ると：

| | 金額 | 割合 |
|---|---:|---:|
| 金額も発生も確定（商品代・代行手数料・梱包） | ¥17,550 | 47% |
| 発生は確定・金額は推定（国内送料 ¥4,000・国際送料 ¥12,700） | ¥16,700 | 45% |
| 二次情報（米国関税 12.5% ¥1,875・USPS $9.35 ¥1,403） | ¥3,278 | 9% |

**総額の約半分が推論。**英国では 59% / 37% / 4%（VAT が公表税率なので確定側に寄る）。

### 順位の頑健性の主張は実測で否定された（2026-09-06）

以前ここには「重量を ×1/10 から ×3 まで外しても1位は動かない」「総額が 46% ずれても
順位は1つも動かない」と書いてあった。**費目を一次情報に直したあとの再測定で、これは
成立しないことが分かった。**（旧測定は EMS 表の丸めと、実在しない費目・存在しない
「Neokyo は国内送料込み」を前提にしていた。）

1位が入れ替わる重量（米国・¥3,000/点・ヤフオク・国内送料あり、25g 刻みで走査）：

| 点数 | 1位が入れ替わる重量 |
|---|---|
| 1点 | **交差なし。**FROM JAPAN が 25g〜24,750g のどこでも1位 |
| 2点 | **1,150g** で Neokyo → FROM JAPAN |
| 3点 | **1,325g** で Neokyo → FROM JAPAN |
| 5点 | **1,625g** で Neokyo → FROM JAPAN。さらに **4,975g** で比較可能な行が Buyee default だけになる |

交差点は 1〜2kg にある。代行で買う品物としてごく普通の重量帯であり、
重量表の推定誤差が容易に跨ぐ幅である。5点 × 600g（既定の推定値）では
**7カ国すべてで `rankStable=false`**。

5点 × ¥3,000・米国の実測（`docs/audit/measured-2026-09-06.md`）：

| 実重量/点（5点） | 1位 | 総額 | 2位との差 | 最下位 |
|---:|---|---:|---:|---|
| 200g | Neokyo | ¥31,128 | ¥1,250 | Buyee, default ¥53,788 |
| 600g（推定値） | Neokyo | ¥37,528 | ¥950 | Buyee, default ¥62,838 |
| 1,500g | Neokyo | ¥52,828 | **¥50（0.1%）** | Buyee, default ¥78,388 |
| 3,000g | **FROM JAPAN** | ¥74,478 | ¥1,300 | Buyee, default ¥96,388 |

600g を基準に ×1/3（200g）で総額は −17%、×3（1,800g）で +54% 動き、**×3 の側では
1位が FROM JAPAN に替わる。**総額の誤差が全社に等しく乗るという以前の説明は、
重量に非線形に効く費目（Neokyo の梱包 ¥500+¥150/kg、EMS の段、Buyee の個口分割）を
無視していた。

実装の `rankStable` は ×1/3 と ×3 の2点で判定する（`src/lib/pricing/compare.ts`）。
それ以上振らないのは、梱包後の重量が EMS 公表表（30kg）を出ると「順位が変わる」ではなく
**「比べられなくなる」**ため。判定できない倍率は「動いた」とは数えない。

### 表の外に出るとき

5点では **4,950g/点**（梱包後 30.0kg）までが公表表の中。これを超えると1個口にまとめる
4社は国際送料を出せず、`comparable:false` になって順位から外れる。注文ごとに分ける
Buyee default だけが表の内側に残り、唯一の比較可能な行として1位になる。
このとき**比較不能な行の総額は1位より安く見える**（最大の費目が欠けているため）が、
順位には出さないし最安にもしない。

> 以前この節には 3,000g/点で「総額を出せない」と書いてあったが、**それは EMS 表を
> 27段（15kg）までしか転記していなかったからで、公表は 42段・30kg まである。**
> さらにその前は 18.3kg を 15kg の料金に丸めて ¥62,178 と書いていた。
> どちらも 2026-09-06 の敵対的監査で発覚し、同日修正した。

### UI への帰結

**現在の素案は強調が逆になっている。**最大の文字が総額（最も不確かな数字）で、
順位と差額（最も確かな情報）が小さい。

意思決定に必要なのは「どれを選ぶか」であって「いくら払うか」ではない。
画面の主役は **順位と差額**、総額は概算として添える。
ただし順位も重量次第で動く以上、`rankStable` と `rankStabilityNote` を隠さずに出し、
不安定なときは「重量の推定が外れると1位が替わる」と書く。**「概ね頑健」とは書かない。**

### 逆転条件

**「送料込み出品だと1位が Neokyo から FROM JAPAN に替わる」も成立しない。**
Neokyo のサービス料に国内送料は含まれない（公式の料金ページは「商品代＋国内送料」に
¥350 を足す形。2026-09-06 の監査 fees.md で修正）。いま5社とも国内送料は別建てなので、
送料込み出品は**全社に等しく効き、1位は動かない**。
7カ国 × 1/2/3/5点 × 200〜3,000g で実測し、`freeShipping` の有無で1位が変わった組み合わせは
1つも無かった。

動くのは順位の中位だけで、**送金合計額に率で乗る費目を持つ社**（ZenMarket の入金手数料
3.5%）が、国内送料が消えた分だけ相対的に得をする。5点 × 200g・米国では ZenMarket が
4位から3位へ上がる（Buyee, consolidated と入れ替わる）。1位が動く条件は、いまのところ
**重量**（上記の交差点）と**個口の分け方**の2つだけ。

## 2. 費目は2軸で分類する

| | 必ず発生 | 条件付き・任意 |
|---|---|---|
| 金額が確定 | 商品代／代行手数料／国内配送サービス料／入金手数料 3.5% | Buyee 保護梱包 ¥1,500・特殊梱包 ¥2,500・通関手数料 ¥2,800・保管延長 ¥100〜300/日／Neokyo 開梱 ¥1,000・コンビニ ¥1,000／ZenMarket 写真 ¥500・再梱包 ¥1,000〜4,000／保証プラン |
| 金額が推定 | 国内送料 ¥150〜1,500／国際送料（重量次第）／VAT（課税ベースが送料に依存） | 梱包の重量加算 |
| 二次情報 | 米国関税 12.5%／USPS $9.35／Royal Mail £8 | FROM JAPAN の手数料体系（定額か率か不明） |
| 取得できていない | — | 米国以外の閾値超関税／カナダの州税／独仏星の通関手数料／カード為替手数料 |

「金額は確定だが発生が不確実」（特殊梱包）と「発生は確定だが金額が不確実」（国際送料）は
性質が逆なので、画面上の扱いも分ける。既定は最小構成で計算し、任意の費目は
「これを選ぶと +¥1,500」として別に見せる。

## 3. 検証済みの一致

ZenMarket の入金手数料は「送金合計額の 3.5%」。¥10,000 をチャージするには
`10000 / (1 - 0.035) = ¥10,362.7` が必要になる。台湾の利用者が公開した実際の請求は
**¥10,363**。実請求と 1 円差で一致した。

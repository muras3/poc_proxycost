# 設計上の制約（実装前のメモ）

## 1. 総額は推論。順位は推論に対して頑健

5点 × ¥3,000 を米国へ送る場合の内訳を確度で割ると：

| | 金額 | 割合 |
|---|---:|---:|
| 金額も発生も確定（公表料金） | ¥16,750 | 50% |
| 発生は確定・金額は推定（国内送料・国際送料） | ¥13,500 | 40% |
| 二次情報（米国関税 12.5%・USPS $9.35） | ¥3,278 | 10% |

**総額の約半分が推論。**英国でも 47% / 53%。

一方、重量の推定を外しても順位は動かない。ただし**動かなくなる範囲には上限がある**
（2026-09-06、5社での再測定。Jauce 追加後・EMS 表の丸め修正後の値）：

| 実重量/点（5点） | 総額 | 1位 | 最下位 |
|---:|---:|---|---|
| 200g | ¥27,128 | Neokyo | Buyee, default |
| 600g（推定値） | ¥33,528 | Neokyo | Buyee, default |
| 1,500g | ¥48,828 | Neokyo | Buyee, default |
| 2,400g | — | Neokyo | Buyee, default |
| **3,000g** | **出せない** | **Buyee, default** | — |

100g〜2,400g/点 では7カ国すべてで 1位 Neokyo・最下位 Buyee default。
重量を **×1/10 から ×3 まで外しても1位は動かない。**

**3,000g/点で起きるのは「順位が入れ替わる」ではなく「比べられなくなる」。**
5点を同梱すると梱包後 18.3kg になり、日本郵便の EMS 公表料金表（15kg まで）の外に出る。
1個口にまとめる4社は国際送料を出せず、注文ごとに分ける Buyee default だけが表の
範囲に収まって唯一の比較可能な選択肢として残る。

> 以前この行には ¥62,178 と書いてあったが、**あれは 18.3kg を 15kg の料金に
> 丸めた値だった。**実装が「持っていない料金を安い側に丸めて出す」形になっていた
> （2026-09-06 の敵対的監査 L3 で発覚、同日修正）。いまは総額を出さず、
> その行を順位から外して理由を画面に書く。

**総額が 46% ずれても順位は1つも動かない。**推定の誤差が全社に等しく乗るため。
表の外に出たときだけ、順位ではなく比較そのものが成立しなくなる。

### UI への帰結

**現在の素案は強調が逆になっている。**最大の文字が総額（最も不確かな数字）で、
順位と差額（最も確かな情報）が小さい。

意思決定に必要なのは「どれを選ぶか」であって「いくら払うか」ではない。
画面の主役は **順位と差額**、総額は概算として添える。

### 逆転条件

国内送料が実際に ¥0（送料込み出品）の場合、**1点のときに限り** 1位が Neokyo から
FROM JAPAN に入れ替わる。Neokyo の「国内送料込み」という優位が消えるため。
**これは推定ではなく、出品ページの `chargeForShipping` から確定できる。**

2点以上では入れ替わらない（2026-09-06 に 1・2・3・5点 × 200〜3,000g で実測）。
Neokyo の ¥350/点 が FROM JAPAN の ¥500/点 + ¥200/注文 に対して点数とともに効くため。

## 2. 費目は2軸で分類する

| | 必ず発生 | 条件付き・任意 |
|---|---|---|
| 金額が確定 | 商品代／代行手数料／国内配送サービス料／入金手数料 3.5% | Buyee 保護梱包 ¥1,500・特殊梱包 ¥2,500・通関手数料 ¥2,800・保管延長 ¥100〜300/日／Neokyo 開梱 ¥1,000・コンビニ ¥1,000／ZenMarket 写真 ¥500・再梱包 ¥1,000〜4,000／保証プラン |
| 金額が推定 | 国内送料 ¥150〜1,500／国際送料（重量次第）／VAT（課税ベースが送料に依存） | 梱包の重量加算 |
| 二次情報 | 米国関税 12.5%／USPS $9.35／Royal Mail £8 | FROM JAPAN の手数料体系（定額か率か不明） |
| 取得できていない | — | 米国以外の閾値超関税／カナダの州税／独仏星の通関手数料／カード為替手数料 |

「金額は確定だが発生が不確実」（特殊梱包）と「発生は確定だが金額が不確実」（国際送料）は
性質が逆なので、画面上の扱いも分ける。既定は最小構成で計算し、任意の費目は
「これを選ぶと +¥1,500」として別に見せる。

## 3. 検証済みの一致

ZenMarket の入金手数料は「送金合計額の 3.5%」。¥10,000 をチャージするには
`10000 / (1 - 0.035) = ¥10,362.7` が必要になる。台湾の利用者が公開した実際の請求は
**¥10,363**。実請求と 1 円差で一致した。

## 撮影データの注意点
- `capture-log-b.json` では **poolsuite・tldraw（desktop/mobile とも）と nothing の mobile は高さ 900／664px**。つまり1画面で終わるアプリ型か、遮断された画面で、scroll1〜3 は fold と同じ内容とみなした。

- mercury の desktop-scroll1 は fold と同じ画像（ヒーロー固定の撮影ずれ）。spline の desktop-scroll1 もほぼ fold と同じ（3D の物体の位置が少し違うだけ）。

## 今回新たに見えた、既存9サイトに無い技法
- **端数を小さく上付きにする金額表示**（Mercury: `$1,374,471` の後ろに小さく `.12`）。主の桁を読みやすくし、細かい桁は残す。
- **請求書型の階層**: 明細 → 小計・税（小・灰・率を括弧に）→ 総額（一段大きく黒）（Ramp）。
- **明細の行に `01` `↳` を付けて、計算の流れを示す**（Ramp）。
- **未確定のセルに「処理中」の点の記号**を置き、空欄と区別する（Ramp）。
- **表の最後の行・右端の列をフェードさせ、続きがあることを示す**（Mercury・Ramp）。
- **画面下に固定したライブのティッカー**で稼働量を流す（Ramp の `AGENTS AT WORK TODAY`）。
- **ラベル（大文字・等幅・小）→ 値（字幅の狭いセリフ・大）の2段組**（Nothing の `LOOKS LIKE YOU'RE IN:` → `JAPAN/日本`）。
- **英語／日本語を斜線でつなぐ併記**（Nothing）。
- **ドットマトリクス書体**をロゴ・アイコン・ラベルだけに使う（Nothing）。
- **注番号の上付き＋画面下のカプセルにまとめた法的注記**を、最初の画面から見せる（Mercury）。
- **AI が読み取った値を、元の書類の上にピルで重ねる**（Mercury の請求書）。
- **見出しの一部だけに地の帯（ハイライト）を敷く**（Amie の `Within 47 seconds:`）。
- **ヒーローに日付付きの更新履歴を1行**（Amie の `Sep 3: …`）、比較対象の名指し（`Replaces:`）、**手書き風の注**。
- **日単位で数えた経過期間や、実数の会員数を散文にそのまま書く**（Are.na の `15 years and 35 days`、`20,516 people`）。
- **空欄の `+` を箇条書きの続きに置き、書き足せるように見せる**（Are.na の `c. +`）。
- **ちぎった紙の切り口・罫線ノート紙・網点のコラージュ**、紙の繊維のノイズの地（Craft）。
- **大文字の小ラベル＋イタリックセリフの説明**の2段（Craft）。
- **線種（実線・破線・点線・なし）を UI の選択肢として並べる**（tldraw）。確度の4段階の凡例とそのまま対応する。副次的な告知を破線の枠で囲む。

- **見本カードの上端にラベルの帯**を付ける（Rive）。見出しの上に、記号付きの色ラベル（`</> RIVE RUNTIMES`）。

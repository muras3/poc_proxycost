# 評価の高いUI 追加10サイトの評価 b1（2026-09-13）

対象: `shots/b01〜b10`（cursor / resend / clerk / supabase / posthog / attio / granola / mymind / things / cosmos）。
full は縮小されて読みにくいため、主に desktop の fold と scroll1〜3 を見た。mobile は posthog・things・resend の fold/scroll1 だけ見た。
静止画のため、動きは画面から読み取れる範囲だけ書き、それ以外は「推測」と明記した。

## 撮影データの注意点
- **posthog** は capture-log の高さが desktop 900 / mobile 664 で、ページ全体が「OS風のウィンドウ」の中でスクロールする作り。scroll1 はウィンドウ内がスクロールした状態で撮れているが、外側のデスクトップ（壁紙・アイコン）は固定。Cookie バナーが右下を隠している。
- **things** は desktop の fold と scroll1 が同じ画像。scroll3 はダウンロード欄まで進んでいるので、途中の撮影だけ失敗した可能性がある。mobile の scroll1 も fold と同じ構図。
- **granola** は全ショットの中央に Cookie のモーダルが出ていて、背景が暗く、見出しの一部が隠れている。色の判断は割り引いて読むこと。
- **attio** は左下の Cookie バナーが、左側のナビの一部を隠している。
- **resend** は desktop の fold に 3D の立方体が写っておらず（右半分が空いている）、mobile の fold には写っている。desktop では描画が遅れたと推測する。
- **cosmos** scroll1 の検索欄のプレースホルダは文字が薄れかけていて、scroll2 では別の例文になっている（打ち替わる演出があると判断できる）。

## b01 Cursor — 参考度 4
- **独自に見える点**: 地は**黄みのある生成り（#F3F1EC 前後）**で、SaaS によくある青白い白ではない。製品画面の後ろに**油彩の風景画**（山・水辺、筆のタッチが残る）を敷き、その上に macOS 風のウィンドウを重ねる。見出しは細めのサンセリフで**サイズを抑えている**（ヒーローでも 28px 程度）。見出しを「黒の一行＋灰の続き」の2段にして、説明と見出しを一つの塊にする。製品画面の中はとても細かい: `IN PROGRESS 2`、`10m`、`+135 -21`、`Thought 4s`、`Read 2 files, 1 directory 1s`、`esc to stop`。CLI の画面は等幅で、`[x] Real-time metrics` のようなテキストのチェックボックス。差し色は抑えた**からし色（Continue ボタン）とオレンジのリンク**だけ。
- **転用できる**: 生成りの地＋油彩（または古地図・版画）の背景に、実際の計算画面を載せる「額縁」の見せ方。**経過時間・件数・差分（+135 -21）を小さな灰字でびっしり添える**書式（`EMS 2.4kg · 3段目 · 公表 2026-09`）。見出しを小さくして中身に場所を譲る。CLI 風の `[x]` 表記で条件を並べる。
- **合わない**: 生成り地そのものは今の proxycost の「オフホワイト」と近く、背景画が無いと差が出ない。絵画の使用権の手配が必要。
- 動き: 左の一覧の回転アイコン（読み込み中の印）が動くと推測。

## b02 Resend — 参考度 3
- **独自に見える点**: 真っ黒の地に、**大きなセリフ体の見出し（白→灰へ縦方向にグラデーション）**。本文は Inter 系で、セリフとの対比が強い。右上から斜めに入る**淡い光の筋**。バッジは緑〜紫の**グラデーションの縁取り**。「Integrate **this weekend**」と、一語だけ紫→水色のグラデーション文字。アイコンは黒いガラス質の立体（封筒）。scroll2 では、`HTTP 200: { "id": "b2ddf145-…" }` が**等幅で何行も並んで下へ薄れていく**演出と、`Delivered` / `Opened` の**配達ログのタイムライン**（時刻 `Sep 13 03:30:58`、宛先・件名・メーラー・OS をチップで区切る）。
- **転用できる**: **配達ログのタイムライン**（状態バッジ＋時刻＋チップ区切りの文）は、国際郵便の追跡表示そのもので、「日本の倉庫 → 検品 → 発送 → 玄関」の段階表示に直結する。同じ形の行を繰り返して下に向けて薄くするのは、「他にもある」ことを見せる手段になる。
- **合わない**: 黒地＋グラデーション文字＋ガラス質のアイコンは、2024〜25年の開発者向け SaaS の定番で、脱量産にならない。
- 動き: HTTP 200 の行が増えていく・光の筋が動くのは推測。

## b03 Clerk — 参考度 3
- **独自に見える点**: ヒーローの背景に**薄い灰色の電子回路（基板の配線とチップ）**の線画。見出しは極太で字間を詰めたグロテスク、2行とも黒。CTA の代わりに**コマンド欄**（`❯ Add Clerk auth to my app: clerk.com/SKILL.md`＋コピーのボタン）を置く。ロゴ帯は**罫線で区切った表のマス**。明るい章から暗い章へ移る境目を、**角を斜めに落とした台形の切り欠き**でつなぐ（scroll1）。暗い章のカードは、指紋・鍵・サーバーラックの**立体的な暗色イラスト**を上、文字を下に置いた型。ラベルを等幅の大文字（`MULTI-TENANCY`、`BILLING`）で並べる折りたたみ。
- **転用できる**: 章の境目を**斜めの切り欠き**で切る（伝票の角・荷札の形として使える）。等幅大文字のラベル＋折りたたみ（`CUSTOMS`、`INSURANCE` のように費用の項目を並べる）。背景に薄い線画を敷く考え方（配線ではなく**航路図・郵便の路線図**に置き換える）。
- **合わない**: 暗色の立体イラストのカードは作るコストが高く、SaaS の機能紹介の型でしかない。
- 動き: `Authenticating...` の回転アイコンなど、カード内に小さな動きがあると推測。

## b04 Supabase — 参考度 2
- **独自に見える点**: 白地に**ミントグリーン（#3ECF8E 前後）1色**。見出しを「黒の1行＋緑の1行」に分ける。お知らせ帯の左右に、`{[<(` のような**括弧記号を並べた ASCII の模様**が薄く入る。機能カードは、ゾウの線画・メールアドレスが並ぶマス・**地球儀のワイヤーフレーム**など、線だけの図。GitHub のスター数 `109K` をナビに置く。scroll1 では、表の作成フォームに実際に `countries` と打たれた状態を見せる。
- **転用できる**: **地球儀のワイヤーフレーム**に経路の点を打つ図（発送元の日本 → 買い手の国）。記号を並べた ASCII 模様を帯の装飾に使う（`→ ✈ ▣` などで作れる）。
- **合わない**: 全体は整った白地の角丸カードで、今の「無難デザイン」と構造がほぼ同じ。

## b05 PostHog — 参考度 3
- **独自に見える点**: サイト全体が**OSのデスクトップを模した画面**。草の壁紙の上に、左右に**デスクトップのアイコン**（Home / Pricing / Docs / Trash…）が並び、本文は閉じる・最大化ボタン付きの**ウィンドウ**の中にある。ボタンは**下に濃い色の段が付いた立体的なオレンジ**（押せそうに見える）。見出しの一語に**マーカーで塗ったような青い下地**、本文の語に黄色の蛍光ペン。タブの選択色は強い紫。マイクロコピーがふざけている: Cookie バナーの見出しが「Legally-required cookie banner」で、実在の政治家の写真に「would be so proud」と添える。
- **転用できる**: **下に段の付いた立体ボタン**（「計算する」を物理的なキーのように見せる）。**蛍光ペンで語を塗る**強調（「送料込み」「関税別」など、見落とされやすい条件だけに塗る）。正直で少し笑える注意書き（「この金額は推定です。郵便局は気まぐれです」程度まで）。
- **合わない**: OS を模した画面全体は、比較ツールの操作を遅くし、モバイルでは崩れる（mobile fold ではウィンドウ枠だけ残っている）。実在の人物を使う冗談は不可。

## b06 Attio — 参考度 4
- **独自に見える点**: 白〜ごく薄い灰の地に、**ページ全体を細い罫線のマス目で区切る**（ロゴ帯・左の章ナビ・右の本文がすべて線で仕切られた表のよう）。見出しは「黒の一文＋灰の続き」で、段落全体が見出しの大きさ。左の章ナビは、今いる章だけ黒＋**左に青い縦線**、他は薄い灰（`Build pipeline` / `Convert leads` / …）。図は、中心のロゴの周りの**同心円の軌道**に `ICP: 98`、`New Exec`、`$5B Series H` といった**色の違う小さなチップ**が浮かぶ。入力欄に `Show me outreac|` と**打ちかけの文字**。
- **転用できる**: **罫線のマス目で画面全体を区切る**レイアウト（角丸カードの代わりに線で仕切る。脱「角丸カード＋薄い影」の直接の答え）。スクロールに連動して今の章が強調される左のナビ（入力 → 順位 → 内訳 → 根拠）。**同心円の軌道図**に5社をチップで浮かべ、中心からの距離を総額にする見せ方。
- **合わない**: 色の違うチップを多用すると、確度の色と混ざって意味が読めなくなる。
- 動き: 左の章ナビがスクロールに合わせて切り替わるのは、縦線の位置から推測。チップが軌道を回るのも推測。

## b07 Granola — 参考度 4
- **独自に見える点**: **タイプライター風のスラブセリフ（Tiempos / GT Alpina 系に見える）の特大見出し**。本文は細いサンセリフ。ボタンは**オリーブ色（#4A5A12 前後）**、`New` バッジは黄緑。製品画面の後ろに、**網点の粗い写真・黒い紙に白い円・蛍光の黄緑の紙**を**コラージュ**のように重ねる（紙を切り貼りした質感）。ページの端に**点線の罫線**でガイドを見せる（scroll1）。さらに見出し「For t…ers」は画面幅いっぱいの特大文字。暗い章は、**傷やかすれのある黒い紙**の質感。Cookie の文言は「OK with Cookies? Not the granola kind.」と、商品名に掛けた冗談。章ナビは `Before the meeting` / `In the meeting` / `After the meeting` と**時間の順**。
- **転用できる**: **コラージュ（網点写真・色紙・手書きの線）を製品画面の後ろに敷く**質感は、切手・荷札・伝票の切り貼りとそのまま合う。点線のガイド線。章を**時間の順**（注文前 → 倉庫 → 発送 → 到着）で分けるナビ。オリーブ＋黄緑という、SaaS で見ない配色。
- **合わない**: 特大のスラブセリフは和文と混ぜると釣り合いが取りにくい。コラージュを表の背景にすると数字が読みにくい。
- 動き: `Enhancing notes` の回転表示など、製品画面が動画的に進むと推測。

## b08 mymind — 参考度 3
- **独自に見える点**: 画面いっぱいの**白い円（日の出・レンズのよう）の周りに、オレンジ〜ピンクのぼかし**。見出しは**文学的な細身のセリフ体（Garamond 系）**で特大、字間を詰めている。本文中の語を**色違いの細い枠のカプセル**で囲む（`notes` `bookmarks` `inspiration`）。ナビの項目の前に**色の違う小さな点**。検索欄は**斜体のセリフ体**で「Search my mind...」。マニフェストの章は、先頭の文字だけ大きな斜体の**書籍風の組版**。scroll2 は `NO vanity metrics` / `NO invasive tracking` / `NO ads` と、**太いオレンジの NO を縦に並べる**否定の一覧。
- **転用できる**: **「NO ○○」を縦に並べる約束の一覧**は、proxycost の信頼の表明にそのまま使える（「NO アフィリエイト順位」「NO 隠れ手数料の省略」）。語をカプセルで囲んで、入力できる例を文章の中に埋め込む（「**2.4kg** の **フィギュア** を **カナダ** へ」を文そのものが入力欄になる形）。
- **合わない**: 暖色のぼかしと文学的なセリフ体は「気分」を売る見せ方で、数値の比較ツールには柔らかすぎる。

## b09 Things — 参考度 2
- **独自に見える点**: 薄い青灰の地に、**立体感の強いアプリアイコン**を中央に1つ。見出しは太い SF Pro。ヒーローの下端を**斜めに切った白い面**が横切る。ダウンロード欄は、端末ごとに**線画のアイコン＋OS条件＋価格（`$49.99 (US)`）＋「view in your currency」の下線リンク**を並べた4列。
- **転用できる**: **価格の直下に「あなたの通貨で見る」を小さな下線リンクで置く**書式は、proxycost の円 → 現地通貨の切り替えにそのまま使える。条件（`macOS 13.3 or later`）と価格を同じ小さな段に並べる型。
- **合わない**: 全体は Apple 流の端正さで、独自性の参考にはならない。
- 注: 撮影で途中のスクロールが取れていないため、中盤の構成は見ていない。

## b10 Cosmos — 参考度 4
- **独自に見える点**: ほぼ白（#F5F4F2 前後）の地に、**黒のカプセル型ボタン**と、字間を強く詰めた大きなグロテスク（Neue Haas / Söhne 系に見える）。**ナビの中央に検索欄を置き、プレースホルダが `Try 'vitsoe shelving'` → `Try 'monochromatic digital art'` と入れ替わる**。検索欄の右に、**色の点を円形に並べたロゴ（虹色の点）**。動画の上に `Watch` と `the film` を**左右に割って**置く。scroll2 の作例カードでは、**写真の上に色コード `#BC361B` のカプセル**を載せ、「色で検索できる」ことを見せる。AI 生成の検出に `Show / Blur / Hide` の**3択のセグメント**。
- **転用できる**: **打ち替わる例文のプレースホルダ**（`Try 'メルカリ 2.4kg カナダ'` → `Try 'ヤフオク フィギュア 米国'`）。ナビの中央に入力欄を常駐させる。**写真の上に数値のカプセルを載せる**（商品写真に `¥18,420 → CA$192` を載せる）。**3択のセグメント**で確度の表示を切り替える（`すべて / 公表のみ / 推定も表示`）。
- **合わない**: 写真を主役にした大きなカードは、比較の表には密度が低すぎる。

## 今回新たに見えた、既存9サイト（a01〜a10）に無い技法
- **油彩・古典絵画を製品画面の額縁にする**（Cursor）。a群の背景はグラデーション・ノイズ・単色帯だけだった。
- **コラージュ（網点写真・色紙・かすれた黒い紙）の切り貼り**（Granola）。紙の質感はa07 Arc にもあるが、複数素材を重ねる切り貼りは無かった。
- **配達ログのタイムライン**（状態バッジ＋時刻＋チップで区切った文）（Resend）。追跡表示としてそのまま使える。
- **罫線のマス目でページ全体を仕切る**＋スクロールに連動して今の章に縦線が付く左ナビ（Attio）。
- **同心円の軌道図に属性チップを浮かべる**図解（Attio）。
- **章の境目を斜めの切り欠き（台形）でつなぐ**（Clerk）。a07 の波形の縁とは別の、角ばった切り方。
- **CTA の代わりにコピーできるコマンド欄**を置く（Clerk）。
- **OS のデスクトップを模したサイト全体**、**下に段の付いた立体ボタン**、**蛍光ペンで語を塗る強調**（PostHog）。
- **ふざけた正直なマイクロコピー**（PostHog の Cookie バナー、Granola の「Not the granola kind.」）。a群のマイクロコピーは事務的だった。
- **「NO ○○」を縦に並べる約束の一覧**、**文中の語をカプセルで囲む**（mymind）。
- **ナビ中央に常駐する検索欄＋入れ替わる例文のプレースホルダ**、**写真の上に数値（色コード）のカプセルを載せる**、**3択のセグメントで表示の度合いを切り替える**（Cosmos）。
- **価格の直下に「あなたの通貨で見る」リンク**（Things）。
- **地球儀のワイヤーフレームに経路の点を打つ**図、**括弧記号の ASCII 模様**の帯（Supabase）。

# 評価の高いUI 10サイトの評価（2026-09-13）

対象: `shots/a01〜a10`。全40枚のうち、判断に要る分を見た（全10サイトの desktop-fold、linear / stripe / vercel / raycast / teenage-engineering の desktop-full、perplexity / teenage-engineering / arc の mobile-fold）。
静止画のため、動きは画面から読み取れる範囲だけ書き、それ以外は「推測」と明記した。

## 撮影データの注意点
- **perplexity は撮り直しても遮断画面**のため「取得不可」とし、評価から除外した（残り9サイトで評価）。
- linear / stripe / raycast / teenage-engineering の **desktop-full は fold と同じ画像**で、下までスクロールした撮影になっていない。スクロール後の構成は見ていない。
- vercel の desktop-full は全ページが撮れているが、中盤から下が空白。スクロールで出てくる要素が撮影時に描画されなかったと推測する。
- framer・superhuman は Cookie バナーが画面の一部を隠している。

## a01 Linear — 参考度 5
- **独自に見える点**: ほぼ黒の地（#08090A 前後）に、白〜灰の段階だけで階層を作る。見出しは字間を詰めた大きめのサンセリフ（Inter Display 系に見える）。ヒーロー直下に**製品画面そのものを最上面の見本として置いている**。イラストは無い。画面の中は、`DRV-8852` のような等幅ID、`1 / 84`、`2min ago` といった小さなメタ情報がびっしり並び、密度が高い。色は状態アイコンの黄色くらいで、ほとんど使っていない。
- **転用できる**: ダークな地に灰の段階で階層を作る。ID・数字は等幅にする。サイドバー＋主パネル＋右の属性パネルの3分割（proxycost なら「入力｜順位｜内訳の根拠」）。確度を、状態アイコンのように**小さな記号＋1色**で表す。
- **合わない**: マーケ用の大きな余白をそのまま持ち込むと、比較ツールとしては間延びする。
- 動き: 右下にAIパネルが重なっている（fold と full で差がある）ので、読み込み後に要素が出てくる演出があると推測。

## a02 Stripe — 参考度 3
- **独自に見える点**: 白地に、ヒーロー右上から流れる**リボン状の多色グラデーション**。見出しは2色使い（濃紺→灰青）で、一文の中で強弱を付けている。**「決済額が世界GDPに占める割合: 1.71464755%」と、小数8桁の数字**を置いている。縦の細い罫線（ページ枠のガイド線）が見えていて、グリッドが目に見える。
- **転用できる**: 桁の多いライブ数字で「今計算している」ことを伝える（fold と full で末尾の桁が違うので、**数字が動いていると判断できる**）。例: 「今日の円相場で換算した総額」。見出しの2色使い（結論を濃く、補足を淡く）。見えるグリッド線。
- **合わない**: 大きなグラデーションの装飾は、数値が主役の画面ではノイズになり、ブランドの印象を借りただけに見える。

## a03 Vercel — 参考度 3
- **独自に見える点**: ほぼ白（#FAFAFA）に黒の三角1つ。周りのぼかし影で立体に見せている。見出しは字間を詰めた Geist。左に見出し、中央にロゴ、右に3行の短文と、3列に大きく余白を取る。以降のセクションは「Zapier serves over 100 million…」のように、**数字＋一行の実例＋Featuresの小さな一覧**が型になっている。
- **転用できる**: Geist / Geist Mono の組み合わせ（数字の等幅と相性がよい）。「大きな数字1つ＋根拠の小さな一覧」という型は、総額と内訳の関係にそのまま使える。
- **合わない**: 白地に余白を多く取るミニマルは、今の「無難デザイン」との差が小さく、脱Claudeにならない。

## a04 Raycast — 参考度 4
- **独自に見える点**: 黒地に、**ざらついたノイズ付きの赤い斜めの帯**（光の筋のように見える）。ナビは角丸の暗いカプセルに収めている。CTA の下に `macOS Tahoe and Apple Silicon required` と**等幅の小さな注記**。キーボード中心の道具らしい見た目。
- **転用できる**: 条件・前提を等幅の小さな注記で書く型（「EMS重量ステップ基準・2026-09時点公表値」など）。ノイズの質感で、単色の地を安っぽく見せない。赤1色をアクセントにする考え方（最安だけに色を与える）。
- **合わない**: 大きなビジュアルのヒーローは、道具ページの先頭には不要。
- 動き: 帯が動く可能性はあるが推測。

## a05 Family — 参考度 2
- **独自に見える点**: 白地に、表情のある丸いキャラクターと、コイン・星などの手描き風イラストが散らばる。見出しは丸みのある太いグロテスク（字間は詰め気味）。黒のカプセル型ボタン。親しみやすさを最優先している。
- **転用できる**: 箱（ParcelView）の描画にほんの少し「表情」を付ける。空の状態や、エラー時の一枚絵。
- **合わない**: 金額と確度が主役のツールに陽気なキャラは信頼感を下げる。広い範囲に使うのは不可。

## a06 Framer — 参考度 3
- **独自に見える点**: 真っ黒な地に、**青く発光する枠線**（ネオンのような縁の光）のガラス風の入力欄。中で文字が打たれている途中の状態（キャレット）を見せ、製品の動きを静止画でも伝えている。
- **転用できる**: 選択中の行や「最安」の行だけ縁を光らせる。検索欄に、打鍵途中の例（`https://jp.mercari.com/item/…`）を見せる。
- **合わない**: ガラス風＋青い発光は2024〜25年の「AIっぽさ」そのもので、逆に量産型に見えるおそれがある。
- 動き: 再生ボタンがあるので動画の埋め込み。打鍵のアニメーションは推測。

## a07 Arc（Dia） — 参考度 4
- **独自に見える点**: **紙のようなノイズの入った群青（#3B3FF5 前後）の帯と、波形の縁取り（切手のギザギザのような境界）**。見出しは太いセリフ体（Fraunces / Recoleta 系に見える）。本文は普通のサンセリフで、セリフの見出しとぶつけている。巨大な引用文を半透明で見せる。遊び心が強いが、中の製品画面はきちんと整っている。
- **転用できる**: **郵便・切手・伝票という比喩と直結する**波形の境界やミシン目。セリフ見出し＋等幅数字の対比。帯で章を区切る（入力｜結果）。
- **合わない**: 群青一色の強い地を全面に使うと、長い表を読むのに疲れる。区切りだけに使う。

## a08 Superhuman — 参考度 3
- **独自に見える点**: 左は暗い紫黒、右は赤紫のグラデーションに製品画面を重ねた2分割。見出しを灰と白の2段にして一部だけ強調（「with **Superhuman Mail**」）。タブに件数を添える（`Important 8`、`Other 200`）。薄いラベンダーのお知らせ帯。
- **転用できる**: タブや絞り込みに件数を添える（「宅配便 3 / 郵便 4」）。一文の中で結論の部分だけ明るくする見出し。左に説明、右に実物画面の2分割。
- **合わない**: グラデーション＋ラベンダーは SaaS の定番で独自性が低い。

## a09 Perplexity — 取得不可（評価対象外）
- 撮り直しても Bot 確認の遮断画面で、中身が写っていない。評価・参考度の付与・3案の参考元のいずれにも使わない。

## a10 teenage engineering — 参考度 5
- **独自に見える点**: 白地に黒のインク、差し色は**オレンジ（#FF5A1F 前後）1色**だけ。極太で字幅の狭い、ステンシル風の見出し（自社書体風）。ナビは**ピクトグラム＋小さな3行の説明**で、機材のパネル表示のように並ぶ。見出しの横に **`EP–133  2.5` のような型番と数値の小さな表**を置く。日本語の小さな縦組みの説明文。劇画調の手描きイラスト。モバイルでは、左上にカート件数 `0` を**機材の表示窓のように**見せる。
- **転用できる**: **型番＋数値の小さな一覧**を見出しの隣に置く書式（`BUYEE  ¥18,420`）。差し色1色の厳格な運用（最安／差額だけオレンジ）。機材のパネル表示・計器・ラベルテープという比喩。件数を「表示窓」に出す見せ方。
- **合わない**: 劇画調のイラストは作るコストが高く、情報密度を下げる。極太の見出しは日本語を混ぜると崩れやすい。

## proxycost が「Claudeっぽさ」を脱するための方向性 3案

### 案A「Customs Ledger（税関の台帳）」
- **比喩**: 国際郵便の伝票・税関申告書（CN23）・切手。紙にスタンプを押し、ミシン目で切り離す。
- **配色**: 伝票紙 `#F2EDE3` / インク `#1B1A17` / 郵便赤 `#D7261E` / 確度が推定の藍 `#2B3A8C`
- **フォント**: 見出し Fraunces（または Instrument Serif）＋和文は Zen Old Mincho／本文 IBM Plex Sans JP／数字 IBM Plex Mono（tabular）
- **インタラクション**:
  1. 1位確定時、行に「CHEAPEST」の**ゴム印が押される**（回転とにじみ、0.2秒）
  2. 内訳を開くと、ミシン目で**伝票の半券がちぎれて下に垂れる**。確度は印の種類で表す（公表＝実線の枠、推定＝点線の枠、二次情報＝手書き風）
- **参考**: Arc（波形の縁取り・セリフ＋ノイズ）、teenage engineering（型番＋数値の一覧）

### 案B「Freight Instrument（計器盤）」
- **比喩**: 郵便局の秤と、機材のパネル表示（7セグ風の表示窓）。重量を入れると針が振れ、段を跨ぐとランプが点く。
- **配色**: 筐体の黒 `#0E0F0C` / パネルの灰 `#C9CCC4` / 信号のオレンジ `#FF5A1F` / 点灯する緑 `#9BE564`
- **フォント**: 見出し Space Grotesk（または Neue Machina）／本文 Inter＋Noto Sans JP／数字 JetBrains Mono または Berkeley Mono（tabular、スラッシュ付きゼロ）
- **インタラクション**:
  1. 総額が**機械式カウンターのように桁ごとに回転**して新しい値に止まる
  2. 重量スライダーを動かすと、EMS重量ステップの境界で**目盛りが「カチッ」と止まり、ランプが点灯する**。`data-crossed` の状態を見える形にしたもの（既存の ParcelView と直結）
- **参考**: teenage engineering（差し色1色・表示窓）、Raycast（等幅の注記・ノイズの黒）、Linear（灰の段階だけの階層）

### 案C「Terminal Manifest（発着ボード）」
- **比喩**: 空港・港の発着案内板（パタパタ表示）と積荷目録（マニフェスト）。5社を便名のように並べ、順位が入れ替わると板がめくれる。
- **配色**: 夜の地 `#0B0D12` / 案内板の黄 `#F5C518` / 文字の白 `#E8E6DF` / 遅延（上限不明）の赤 `#E5484D`
- **フォント**: 見出し Geist（字間を詰める）／本文 Geist＋Noto Sans JP／数字 Geist Mono（案内板の部分だけ、表示板風の書体にしてもよい）
- **インタラクション**:
  1. 条件を変えると**順位表の文字がフラップ式にめくれて並び替わる**（FLIPアニメーション＋文字のスクランブル）
  2. `⌘K` 風のコマンドバーから「送り先 CA / 重量 2.4kg」と打つだけで条件を変えられる。確度は案内板のステータス欄（`CONFIRMED` / `ESTIMATED` / `UNVERIFIED`）で表す
- **参考**: Linear（ダーク・3分割・等幅ID）、Stripe（動くライブ数字）、Superhuman（件数付きタブ・キーボード中心）、Vercel（Geist）

### 補足
- どの案でも、今の `tier` の4段階（fixed / estimate / unverified / none）は色だけに頼らず、**記号・枠線・ラベル文字**で表す。今の「点線の下線」「`~`」の規約を、比喩に合わせて置き換えるのが安全。
- 無彩色＋差し色1色を守れば、shadcn の部品を土台にしてもトークンで独自性を出せる。

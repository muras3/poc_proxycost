# proxycost デザイン方向性 3案（改訂版）

根拠: 類似 20（eval-proxy-services.md / eval-comparison-tools.md）＋ 非類似 29（eval-acclaimed-ui.md / -b1.md / -b2.md）。
初版の 3 案（eval-acclaimed-ui.md 末尾）に、追加 20 サイトで見えた技法を足して作り直した。

## 3案に共通する土台（どれを選んでも入れる）

類似サイトから、比較ツールとして外せない型を持ってくる。

- **総額の列を右端に太字で置き、並び順の基準にする。各行に 1 位との差（+¥）** — Wise
- **スマホは 1 位カード＋残り 4 社の短いリスト** — Monito
- **請求書型の階層**: 明細（`01` `↳` で計算の流れ）→ 小計・税（小・灰・率は括弧）→ 総額（一段大きく） — Ramp
- **金額は右寄せ・等幅（tabular）、端数は小さく** — Mercury
- **確度 4 段階を線種で表す**: 公表＝実線 / 推定＝破線 / 二次情報＝点線 / 未取得＝線なし＋「処理中」の点の記号 — tldraw・Ramp。色だけに頼らない
- **前提条件・為替・料金表の確認日を、結果の枠の縁に帯として付ける** — Poolsuite の窓の帯、Wise の表下の注記
- **表示通貨の切り替えを総額の直下に** — Things
- **角丸カード・オフホワイト・薄い影・テラコッタは使わない。罫線のマス目で区切る** — Attio
- 割引ポップアップや広告は置かない（代行 11 社との最大の差別化点）

## 案A「Customs Ledger ── 税関の台帳」

**一言で**: 国際郵便の伝票（CN23）と切手の束。紙に数字を書き込み、1 位にゴム印を押す。

- **比喩の根拠**: 送料・関税・通関手数料という題材そのもの。FROM JAPAN / Doorzo の「Charge 1 / Charge 2」の 2 回払いを、伝票の 2 枚綴りとして自然に表せる
- **配色**: 伝票紙 `#F2EDE3` / インク `#1B1A17` / 郵便赤 `#D7261E` / 推定の藍 `#2B3A8C`
- **書体**: 見出し Instrument Serif ＋ Zen Old Mincho / ラベル IBM Plex Mono（大文字・小） / 本文 IBM Plex Sans JP / 数字 IBM Plex Mono（tabular）
- **質感**: 紙の繊維のノイズ、ちぎった紙の切り口、網点の切手コラージュ（Craft・Granola）。背景に一点だけ古い郵便の版画（Cursor の「絵画を額縁に」の応用）
- **インタラクション**
  1. 1 位が決まると行に `CHEAPEST` の**ゴム印が押される**（回転・にじみ、0.2 秒）
  2. 内訳を開くと**ミシン目から半券がちぎれて下に垂れる**。中は請求書型の階層
  3. 小ラベル（大文字等幅）→ 値（セリフ・大）の 2 段で総額を見せる（Craft・Nothing）
- **マイクロコピー**: 事務的な伝票の語彙に、ときどき正直な一言（PostHog / Granola の「ふざけた正直さ」を控えめに）。例: `推定 — 公表の料金表が無い費目です`
- **強み**: 最も独自で、競合にも AI 量産デザインにも似ない。確度の線種が「伝票の記入欄」として無理なく溶ける
- **弱み**: 質感素材の制作コストが高い。やり過ぎるとレトロ趣味に見え、数字の読みやすさを削る
- **参考**: Arc, Craft, Granola, Cursor, teenage engineering, Mercury

## 案B「Freight Instrument ── 秤と計器盤」

**一言で**: 郵便局の秤と、機材のパネル。重量を入れると針が振れ、料金の段を越えるとランプが点く。

- **比喩の根拠**: proxycost の総額を一番大きく動かすのは重量の段（EMS の重量ステップ・箱の分割）。既存の ParcelView（箱の絵・`data-crossed`）と直結する
- **配色**: 筐体の黒 `#0E0F0C` / パネルの灰 `#C9CCC4` / 信号のオレンジ `#FF5A1F` / 点灯の緑 `#9BE564`（ライトモードはパネルの灰を地に反転）
- **書体**: ラベル・ロゴだけドットマトリクス（Doto など） / 見出し Space Grotesk / 本文 Inter ＋ Noto Sans JP / 数字 JetBrains Mono（tabular・スラッシュ付きゼロ）
- **質感**: 黒の地に細かいノイズ、パネルのネジ穴と刻印の型番（teenage engineering・Raycast）
- **インタラクション**
  1. 総額が**機械式カウンターのように桁ごとに回って止まる**
  2. 重量スライダーが EMS の段の境界で**カチッと止まり、ランプが点く**
  3. 画面下に**固定のティッカー**で「為替 1 USD = ¥… ・料金表確認 9/13」を流す（Ramp の `AGENTS AT WORK TODAY`）
  4. 送り先・重量の欄に**入れ替わる例文**（`CA / 2.4 kg / 5 items`）を打ちかけで見せる（Cosmos・Attio）
- **強み**: 「重量を変えると順位が変わる」という proxycost 固有の面白さを、触って分かる形にできる。黒地・等幅数字で数字の信頼感が高い
- **弱み**: 黒地の計器は開発者ツール（Linear / Raycast）に寄り、買い物客には硬く見えるおそれ
- **参考**: teenage engineering, Nothing, Raycast, Linear, Ramp, Cosmos

## 案C「Terminal Manifest ── 発着ボードと積荷目録」

**一言で**: 空港の発着案内板と積荷目録。5 社を便名のように並べ、条件を変えると板がパタパタとめくれて並び替わる。

- **比喩の根拠**: 「倉庫 → 通関 → 玄関」という配送の段階と、複数社の横並び比較の両方を一枚で表せる
- **配色**: 夜の地 `#0B0D12` / 案内板の黄 `#F5C518` / 文字の白 `#E8E6DF` / 上限不明の赤 `#E5484D`
- **書体**: 見出し・本文 Geist ＋ Noto Sans JP / 数字 Geist Mono / 案内板の部分だけ表示板風の書体
- **質感**: 質感は抑え、罫線のマス目と、スクロールで今の章に縦線が付く左ナビ（Attio）
- **インタラクション**
  1. 条件を変えると**順位表の文字がフラップ式にめくれて並び替わる**（FLIP ＋文字スクランブル）
  2. 1 社を開くと**配達ログのタイムライン**（`購入 → 倉庫到着 → 梱包 → 輸出通関 → 輸入通関 → 玄関`、各段に費目と確度のチップ）（Resend）
  3. `⌘K` のコマンドバーで「CA 2.4kg」と打つだけで条件を変える（Superhuman・Clerk のコマンド欄）
  4. 確度はステータス欄の文字で出す: `CONFIRMED` / `ESTIMATED` / `SECONDARY` / `PENDING ···`
- **強み**: 比較表・順位入れ替え・配送段階の 3 つを一番素直に表せる。実装は 3 案で最も軽い（質感素材がほぼ要らない）
- **弱み**: ダーク＋Geist は Vercel / Linear 系の「今どきの SaaS」に最も近く、独自性は 3 案で一番弱い
- **参考**: Linear, Attio, Resend, Superhuman, Stripe, Vercel

## 比べると

| | A 税関の台帳 | B 秤と計器盤 | C 発着ボード |
|---|---|---|---|
| 独自性 | ◎ | ○ | △ |
| 数字の読みやすさ | ○ | ◎ | ◎ |
| proxycost 固有の面白さ（重量・確度）との結び付き | ○（確度） | ◎（重量） | ○（配送段階） |
| 買い物客への親しみ | ◎ | △ | ○ |
| 実装の軽さ | △ | ○ | ◎ |

**推し**: A を土台に B の「重量の段でランプが点く」秤だけを部品として借りる組み合わせ。独自性と、proxycost 固有の面白さの両方が立つ。

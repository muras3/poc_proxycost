# ① O3 取得の実行計画 ── 5社のアカウントを作り、1円も払わずに明細画面まで行く

2026-09-07。`docs/MASTER.md` の `?` 89セルのうち、**代行会社側を購入ゼロで潰す**ための手順。

## 結論：オークションを避けて「店舗商品」を使えば、支払い前に明細が見える

**5社中4社は公式に根拠がある。**Jauce だけリスクが残る。

| 会社 | 支払い前に明細が出るか | 根拠 |
|---|---|---|
| **ZenMarket** | **○** | 公式：「**注文前にデポジットする必要は本当はありません。商品代や国内送料が請求されてからで構いません**」（payment.aspx） |
| **Neokyo** | **○** | 公式 FAQ：「**Each purchase request will display a preview of your costs and commissions.**」 |
| **FROM JAPAN** | **○** | 公式：デポジットは**支払方法の1つ**であって必須ではない（クレカ/PayPal/Alipay/deposit/FJポイント）。「手動見積が要る店舗は Charge 1 の請求まで最大2営業日」＝**見積が先** |
| **Buyee** | **○（見込み）** | デポジット不要で発注できる。公式の手順は「カート → 代理購入を依頼 → **確認ページでプランと支払方法を選ぶ**」。明細はこの確認ページ。※公式ページに「ここに明細が出る」とは書かれていないので**現物で確認が要る** |
| **Jauce** | **△ 未確認** | オークションは**入札前にデポジット必須**（公式）。モールはベータで手数料無料だが、**デポジット要否が公式に書かれていない**。5社中ここだけリスク |

### オークションを使ってはいけない理由（公式）

- **ZenMarket**：入札には「最大入札額＋サービス料」以上のデポジットが必要
- **FROM JAPAN**：JDirectItems Auction / eBay の入札は「**落札終了時刻から12時間以上有効なデポジット**」が必要
- **Jauce**：入札前にデポジットが必要
- **どの社もオークションは落札後キャンセル不可**

→ **全ケースを「店舗商品（Amazon / 楽天 / Yahoo!ショッピング）」で組む。**

## 課金が発生する境界線（ここを越えない）

| 会社 | 止まる場所 | 越えると |
|---|---|---|
| ZenMarket | 見積が出た画面 | デポジットして初めて課金 |
| Neokyo | Buy Request のプレビュー | 支払を確定すると課金 |
| FROM JAPAN | **Charge 1 の請求が来た時点** | **Charge 1 を払うとキャンセル・返品・売主へのクレームが一切できない**（公式明記） |
| Buyee | 確認ページ（「私に代わって注文する」を押す前） | 押すと購入手数料が発生 |
| Buyee | **「Ship Directly」を選ばない** | **全額前払いになる**うえ、同梱も保護梱包も使えなくなる（公式） |
| Jauce | 未確認 | デポジットを求められたら**そこで止める** |

**FROM JAPAN の Charge 1 が最も危険。**画面に金額が出た時点で目的は達成なので、そこで止める。

## 商品の選び方

5社が**同じ URL を受け付ける**店舗商品を使う。3構成 ＋ 閾値テスト1件。

| 組 | 構成 | 埋めたい `?` |
|---|---|---|
| **A** | 安い薄物 単品（¥1,000前後・送料無料の出品） | 最低重量帯、固定手数料、**「送料無料」でも国内送料が出るか**（Buyee 公式が警告している挙動の現物確認） |
| **B** | 箱物 単品（¥5,000前後・国内送料が有料の出品） | 国内送料の実額、梱包料、重量段 |
| **C** | **2店舗から3点**（うち2点は同一店舗・同一商品） | **F04（同一商品の複数個は手数料1回）を5社で確認**、注文の数え方、まとめ梱包 |
| **D** | **¥210,000 の単品**（20万円を跨ぐ） | **F26 輸出通関 ¥2,800 が ZenMarket と Neokyo にも出るか**。出れば B推論 → A確定に昇格 |

**組Dが一番価値が高い。**現在 B推論の2行が、1円も払わずに確定できる。

## 各画面で必ず取ること

明細画面が出たら、**そのまま次に進まず**に以下を記録する。

1. **明細行を1行ずつ**（項目名・金額・単位）。項目名は**原文のまま**（訳さない）
2. **配送方法を全部切り替えて、それぞれの国際送料**
   - 船便 / ePacket / Small Packet / EMS / DHL / FedEx / UPS
   - → スペインで見つけた「**便で 2.3 倍・EMS が最も高い部類**」が全社・全国で成り立つかの検証
3. **配送先の国を切り替えて、代理徴収される税があるか**
   - **豪州**（GST 10% が明細に出るか＝F36 の確認）
   - **EU（ドイツ）**（VAT 前払いの選択肢が出るか＝DDU/DDP 軸の確認）
   - 米国・カナダ・英国・シンガポール
4. **画面のスクリーンショット**（日時が入る形で）
5. 氏名・住所・電話・カード番号は**消してから保存**

## 未確認のまま残ること

| 項目 | 理由 |
|---|---|
| **登録フォームの入力項目**（メールだけか、住所・電話が要るか） | 公式ページに記載が無い。**現物を見ないと分からない** |
| **Jauce のモール商品でデポジットが要るか** | 公式に記載が無い。**ここだけ止まる可能性がある** |
| **Buyee の確認ページに明細が出るか** | 手順は公式にあるが「明細が出る」とは書かれていない |
| 各社の本人確認の有無 | 未取得 |

**この3つは実際に登録してみないと確定しない。**先に調べ切ることはできない。

## 順序

1. **ZenMarket**（明細前デポジット不要が公式に明記されている＝最も安全）
2. **Neokyo**（プレビューが公式に明記）
3. **Buyee**（デポジット不要。ただし Ship Directly を避ける）
4. **FROM JAPAN**（Charge 1 の請求が来た時点で止める）
5. **Jauce**（デポジットを求められたら止める。5社中ここだけ完走できない可能性）

**1社目で「本当に払わずに明細が見えるか」を確認してから、残り4社に広げる。**
最初から5社同時に進めない。

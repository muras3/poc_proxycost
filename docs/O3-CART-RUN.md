# ① カート画面の明細を取る ── 依頼用プロンプト

**この文書はそのまま作業者に渡せる形で書いてある。**渡す相手は、自分のPCでブラウザが使える人／エージェント（Cowork など）。

計画は `docs/O3-PLAN.md`（根拠と各社の公式引用はそちら）。**この文書は手順だけ。**

---

## 依頼者が先に決めること（作業者が勝手に決めてはいけない）

**この作業は5社に実在のアカウントを作る。**メールアドレス、たいてい氏名・住所・電話が要る。

- **誰の情報を使うか**は依頼者が決める。**作業者が勝手に個人情報を入れない**
- 使い捨てメールで足りるかは登録フォームを見ないと分からない（`O3-PLAN.md` の「未確認のまま残ること」）
- **配送先住所は本物が要る可能性が高い**（国別の税を見るために国を切り替える）

**ここが決まっていなければ、始めずに依頼者に聞くこと。**

---

## この作業で決まること

`poc_proxycost` は代行5社（Buyee / ZenMarket / Neokyo / FROM JAPAN / Jauce）経由で日本の商品を7カ国へ送るときの**総額**を予測して比較するサイト。

いま総額の 84% は各社の公表料金表から来ている。**残り 16% は我々の推定と二次情報で、その正しさを誰も確かめていない。**

**5社とも、決済ボタンを押す前に手数料・国内送料・想定送料の明細が画面に出る。**
つまり **1円も払わずに、同じ入力に対する各社の明細行が取れる。**それがこの作業。

`docs/MASTER.md` に未確定セルが 89 ある。内訳: Neokyo 23 / Jauce 19 / Buyee 18 / FROM JAPAN 14 / ZenMarket 11。**Buyee は5社中ここだけ二次情報しか無い費目が5つある。**

## 絶対に越えない線（金が発生する境界）

| 会社 | **止まる場所** | 越えると |
|---|---|---|
| ZenMarket | 見積が出た画面 | デポジットして初めて課金 |
| Neokyo | Buy Request の**プレビュー** | 支払を確定すると課金 |
| Buyee | 確認ページ（「私に代わって注文する」を**押す前**） | 押すと購入手数料が発生 |
| **FROM JAPAN** | **Charge 1 の請求が画面に出た時点** | **Charge 1 を払うと、キャンセル・返品・売主へのクレームが一切できなくなる（公式明記）。最も危険** |
| Jauce | デポジットを求められたら**そこで止める** | 5社中ここだけ完走できない可能性がある |

### そのほかの禁止

- **オークションを使わない。****店舗商品（Amazon / 楽天 / Yahoo!ショッピング）だけ**を使う
  - 理由: ZenMarket・FROM JAPAN・Jauce は**入札前にデポジットが必須**（各社公式）。**どの社もオークションは落札後キャンセル不可**
- **Buyee で「Ship Directly」を選ばない。**選ぶと**全額前払い**になり、同梱も保護梱包も使えなくなる（公式）
- **CAPTCHA を回避しない。**出たら止めて報告
- **本人確認（身分証の提出）を求められたら止めて報告。**勝手に出さない
- **カード情報を登録しない。**明細を見るのに要らないはず。要求されたら止めて報告

---

## 順序 ── 1社ずつ。同時に進めない

**1社目で「本当に払わずに明細が見えるか」を確かめてから、残りに広げる。**

1. **ZenMarket** —「注文前にデポジットする必要は本当はありません」と公式が明記。**最も安全なので最初**
2. **Neokyo** — 「Each purchase request will display a preview of your costs and commissions.」（公式FAQ）
3. **Buyee** — デポジット不要。**Ship Directly を避ける**
4. **FROM JAPAN** — **Charge 1 が出たら即停止**
5. **Jauce** — デポジットを求められたら停止

---

## 買い物カゴの構成 ── 4つ

**5社が同じ URL を受け付ける店舗商品**を選ぶ。

| 組 | 構成 | これで何が分かるか |
|---|---|---|
| **A** | 安い薄物 単品（¥1,000前後・**送料無料**の出品） | 最低重量帯、固定手数料、**「送料無料」でも国内送料が請求されるか**（Buyee 公式が警告している挙動の現物確認） |
| **B** | 箱物 単品（¥5,000前後・**国内送料が有料**の出品） | 国内送料の実額、梱包料、重量段 |
| **C** | **2店舗から3点**（うち2点は同一店舗・**同一商品**） | **同一商品を複数買っても手数料が1回か**を5社で確認、注文の数え方、まとめ梱包 |
| **D** | **¥210,000 の単品**（20万円を跨ぐ） | **輸出通関手数料 ¥2,800 が ZenMarket と Neokyo にも出るか** |

**組Dが一番価値が高い。**いま我々の推測でしかない2行が、1円も払わずに確定する。
**時間が無ければ A と D だけでよい。**

## 明細画面が出たら、進む前に記録する

1. **明細行を1行ずつ**（項目名・金額・単位）。**項目名は原文のまま。訳さない**
2. **配送方法を全部切り替えて、それぞれの国際送料**
   船便 / ePacket / Small Packet / EMS / DHL / FedEx / UPS
3. **配送先の国を切り替えて、代理徴収される税が明細に出るか**
   - **豪州**（GST 10% が出るか）
   - **ドイツ**（VAT 前払いの選択肢が出るか）
   - 米国 / カナダ / 英国 / シンガポール
4. **スクリーンショット**（日時が入る形で）
5. **氏名・住所・電話・カード番号は消してから保存**

## ついでに取れるもの（ログインしていれば見える）

- **ZenMarket の入金手数料の支払方法別の表** … `profile/addfunds.aspx`。いま「PayPal 3.2%＋¥40」は我々の推測
- **Buyee に「国内配送サービス料 ¥500」が本当に無いか** … いま我々は「無い」と推測しながら**コードでは計上している。**明細で決着する

## 出力の形

**1見積 = 1オブジェクト。**

```jsonc
{
  "id": "o3-zenmarket-A-de-2026-09-XX",
  "stage": "cart_quote",              // 決済前の見積画面
  "company": "zenmarket",
  "country": "DE",
  "input": {
    "item_url": "...", "item_price_jpy": 1050, "qty": 1,
    "marketplace": "rakuten",
    "listed_domestic_shipping": 0, "free_shipping": true,
    "shipping_method": "EMS", "payment_method": "paypal"
  },
  "screen_lines": [                    // **画面の原文のまま。訳さない**
    { "label_raw": "Item price",    "amount": 1050, "currency": "JPY" },
    { "label_raw": "ZenMarket fee", "amount": 500,  "currency": "JPY" }
  ],
  "shipping_by_method": { "EMS": 3650, "DHL": 4200, "SAL": 2100 },
  "tax_shown": { "AU": "GST 10% が明細に出た", "DE": "出なかった" },
  "evidence": "evidence/2026-09-XX-zenmarket-A-de.png",
  "checked_on": "2026-09-XX",
  "notes": "気づいたことは何でも"
}
```

**`label_raw` を訳さないこと。**「Item price」を「商品代」に直すと、その社がどう呼んでいるかが消える。我々は画面の全行を費目に対応づけて**未対応が0件か**を確かめるので、原文が要る。

## 報告

1. 上の JSON（社 × 組ごと）
2. **社ごとに1行で:**
   - `ZenMarket: 組A・D 完了 / 明細9行 / 支払わずに見えた`
   - `Jauce: デポジットを要求されたので停止`
3. **やってみて分かった障害**（登録に住所が要った・本人確認を求められた・明細が出ない など）。**これも成果**
4. **越えそうになった線があれば必ず書く。**「Charge 1 の画面が出たので止めた」は重要な情報

---

## 補足：なぜ買わずに済むのか

「代行に頼む＝先に金を払う」と思われがちだが、**5社中4社は公式に『明細を見てから払う』と書いている。**
オークションだけがデポジット必須で、**店舗商品にはその縛りが無い。**
だからオークションを避けるだけで、この作業は無料で終わる。

**Jauce だけは公式に記載が無い。**そこで止まっても、それは失敗ではなく「5社中4社で取れた」という結果。

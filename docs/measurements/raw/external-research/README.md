自動化エージェントによる実測ではなく、**オーナーが外部に委託した調査の成果物

そのまま `docs/measurements/raw/` 配下の1サブディレクトリとして残り、

（索引の再構築や重複作成はしていない）。#118が未マージの間は、この

## 読み方の注意

この5ファイルは「代行5社の計算機を実測した記録」ではなく、**運送会社・税関等の
公式ページを読んだ二次調査の記録**（第1弾）と、**その実請求書を今後どう入手するかの
設計案**（第2弾）。`docs/PRINCIPLES.md` 原則5（「ページを読んだ」
と「実請求で確認した」は別軸）がそのままこの評価軸になる —
一次資料への到達を確認できた記述であっても、それが「実際にプロキシ5社の請求に
反映されている」ことの証明にはならない。第2弾の`proxy_invoice_evidence_ledger_2026-09-13.xlsx`は
特に、ファイル名（「evidence ledger」）から実請求データの一覧を連想しやすいが、
**中身はテンプレートと見積りであって、入手済みの実請求ではない**——詳しくは
`docs/audit/invoice-collection-2026-09-13.md` を見ること。詳細な評価は
`docs/audit/` の監査ノートを見ること。

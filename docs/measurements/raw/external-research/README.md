## 読み方の注意

この2ファイルは「代行5社の計算機を実測した記録」ではなく、**運送会社・税関等の
公式ページを読んだ二次調査の記録**。`docs/PRINCIPLES.md` 原則5（「ページを読んだ」
と「実請求で確認した」は別軸）がそのままこの2ファイルの評価軸になる —
一次資料への到達を確認できた記述であっても、それが「実際にプロキシ5社の請求に
反映されている」ことの証明にはならない。詳細な評価は `docs/audit/` の監査ノートを見ること。

## 読み取れること

1. **`?` が 85 セル（180 セル中）。**「網羅されているか」の答えは現時点で **No**。
   ただし**空欄は1つも無い**ので、あと何を調べればいいかは全部特定できている。

2. **37 費目に対して、現行コードのスロットは 11（3割未満）。**
   F26（輸出通関）・F36（代理徴収）・F04（同一商品の複数個）は**数字を入れる場所が無い。**

3. **過大計上の疑いが2件。**
   - **F05：Buyee の国内配送サービス料 ¥500。**現行コードは計上しているが、公式ページに記載を見つけられなかった。
   - **F04：同一商品の複数個。**2社が「1回だけ」と明記しているのに、現行は点数ぶん掛けている。

4. **一次情報と二次情報が食い違った実例。**
   - Buyee の手数料：二次「6%＋¥300」／公式「¥500 定額」（**4.5倍違う**）
   - ZenMarket の保管無料期間：DutyGlobal「45日」／**公式「60日」**

   二次情報は費目の存在を知るには使えるが、**金額には使えない。**

5. **`?` の多い社ほど、実際の請求書（O3/O5）で確かめる価値が高い。**
   Neokyo（23）→ Jauce（19）→ Buyee（18）の順。

## 調査手段についての記録

- **ブラウザ操作（Playwright / Chromium）はこの環境では使えなかった。**
  プロキシが Chromium の TLS ハンドシェイクを落とす（`1816 B sent, 39 B received` の直後に reset）。
  ZenMarket だけでなく、curl で 200 が返る neokyo.com でも同じく失敗したので、
  サイト側のブロックではなく**環境の制約**。
- **Wayback Machine もこの環境から到達不可**（`ws_closed_mid_exchange`）。
- **サーバ側で取得して本文を返す reader サービス（`r.jina.ai`）で ZenMarket が読めた。**
  403 は Cloudflare によるデータセンター IP の遮断なので、別 IP から取れば解決する。
  これで5社すべて一次情報が揃った。

# 実データによる重量推定（未実装・検証のみ）

`src/data.js` の `WEIGHT_BY_CATEGORY` は根拠のない仮定だった。実データで置き換えられる。

## データ源

Solaris Japan（日本の趣味品を海外へ売る Shopify ストア）は、Shopify の公開商品 JSON に
**全商品の発送重量 `grams`** を出している。認証もキーも不要。

    https://www.solarisjapan.com/products.json?limit=250&page=N

**5,000件を22秒で取得。**全件に重量あり。`weights-solarisjapan.json` がその生データ。

## 分かったこと

| 商品ライン | 件数 | 中央値 | P25 | P75 | ばらつき |
|---|---:|---:|---:|---:|---:|

| 1/6 scale | 641 | 1,800 g | 1,800 | 1,800 | **1.0x** |
| 1/4 scale | 198 | 3,000 g | 3,000 | 3,800 | 1.3x |
| 1/8 scale | 105 | 1,300 g | 1,230 | 1,500 | 1.2x |
| Nendoroid | 426 | 439 g | 380 | 600 | 1.6x |
| Pop Up Parade | 104 | 800 g | 800 | 1,000 | 1.2x |

**スケール表記のある商品は、ばらつきが 1.0x＝事実上一定。**推定ではなく確定値として扱える。
スケールはヤフオクのタイトルにも「1/7」「1/6」と書かれるので、そのまま照合できる。

## 精度（フィギュア 4,747件で評価）

| モデル | 重量の中央誤差 |
|---|---:|
| 現行（カテゴリ一律 600 g） | **54%** |
| 商品ライン別 | **9%** |

現行モデルは、大型スケールフィギュアの総額を最大 ¥24,150 過小に表示していた。

## 限界（正直に）

- Solaris の `grams` は実測ではなく、同社が梱包区分ごとに置いた標準値の可能性が高い
  （1/7 が全件 1,500 g ちょうどなのはそのため）。EMS の段を引く用途には十分だが、
  「実測重量」ではない
- 5,000件のほぼ全部が Figure。衣類・ゲーム・カメラ・文具は別のデータ源が要る
- タイトルは英語。日本語のヤフオク出品と照合するには、スケール表記（1/7 等）と
  ライン名（ねんどろいど / Nendoroid、figma、ぷちぷちゃ 等）の対応表が要る

## 同じ手が使える他の項目

- **他カテゴリの重量**：日本の趣味品を扱う Shopify ストアは他にもある。同じ JSON が取れる
- **国内送料**：ヤフオクの出品は配送方法（ゆうパック 60サイズ 等）を持つ。サイズ別料金は公表されている
- **関税率**：USITC の HTS API が使える（実際に叩けた）

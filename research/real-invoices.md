# 実請求の収集結果（世界中のブログ・掲示板・SNS 横断）

2026-09-07。多言語・多媒体を横断して、**実際に払った金額の明細**を探した記録。

---

## 結論：落ちてはいるが、完全な明細は極めて少ない

| | 件数 |
|---|---:|
| **1注文の全行が揃った完全な着地明細** | **1件** |
| ほぼ完全（税が不明 or 1回目の内訳が粗い） | 3件 |
| 金額の断片（見積と実額の差、単一費目） | 多数 |

**「請求書が落ちていないわけがない」は半分正しく、半分外れ。**
費目の名前は大量に落ちているが、**1注文の全行を通しで最後まで書いた記録はほぼ無い。**

理由は構造的：支払が2回に分かれ、輸入税は数週間後に配送業者から別請求で来るので、
**書き手が最後まで追わない。**「届いた」で記事が終わる。
だから proxycost が本当に必要としているデータ（配達完了までの全額）は、
世の中に**ほとんど存在しない。**

| 行 | 金額 |
|---|---:|

| （小計） | ¥41,417（€267.13） |

| **UPS 通関管理手数料** | **€15.90 ＝ 税額 €56.15 の 28.3%** |
| **↑ その手数料にかかる IVA 21%** | **€3.34** |

**商品代の 2.15 倍。**投稿者自身が「日本での商品価格を2倍すれば最終額の目安」と書いている。

### この1件がマスタに与える影響

1. **配送業者の通関手数料は parcel あたり定額ではなく、関税額に比例する。**
   現行 `clearanceFeePerParcel`（parcel 定額）ではこの形を書けない。
2. **その手数料自体に VAT がかかる。**税に対する税。費目として存在しない。
3. スレッドは139ページあり、**FedEx / DHL の管理手数料が高いので Correos / 日本郵便（Small Air / Airmail / EMS）を使え**という警告が繰り返されている
   → **配送業者の選択が着地総額を大きく変える。**現行モデルは EMS 固定。

出典：BEENOS プレスリリース 2019-12-18（**一次情報**）

会員かどうかで手数料体系が変わる。F12 の別形。ページは 403 で詳細未取得。

### Buyee Cart は別の料金ページを持つが、基本構造は同じ

出典：bc.help.buyee.jp/en/fee/（**一次情報**）
- 1回目：商品代（税込）／購入手数料 **¥500/注文**／保証プラン **最大¥500**
- 2回目：国内送料（実費）／国際送料（実費）／**Special fees: 実費（国ごとの GST・税）**／オプション

→ **Buyee も F36（会社が輸入税を代理徴収）を持つことが公式で確定。**

### 台湾の免税条件に「輸入回数」がある

完税価格 NT$2,000 未満 **または 半年間の輸入回数が6回未満** で免税。
→ 国の税ルールに**利用者の輸入履歴依存**という軸がある。現行モデルに無い。

### Buyee は「送料無料」でも国内送料が発生しうると公式明記

出典：buyee.jp/helpcenter/guide/fees（**一次情報**）
> In principle, we require sellers/stores to use trackable shipping methods…
> Therefore, domestic shipping fees may occur due to a change of shipping method,
> even though "Free shipping" might be stated on the product page.

→ 出品ページの `freeShipping` を信じて ¥0 にする現行ロジックは、Buyee では外れる。

### Buyee の国内送料は「注文ごと」だが、購入手数料は「同一店舗なら1回」

出典：同上（**一次情報**）
> we process each order respectively, even if multiple orders are purchased through
> the same seller/store. Because of this, there will be separate domestic shipment fees for each order.
> （購入手数料は）Even if multiple purchases are from the same store, it is a flat rate of ¥500.

→ **手数料と国内送料で数え方が違う。**同じ `items.length` を両方に使うのは必ず間違う。

# 第2次探索：スペイン向けの実額が大量に出た

`elotrolado.net`「Aduanas ya no perdona ni una」（139ページ）から12ページを取得。
**スペイン向けの着地費用は、ここだけでほぼモデル化できる量がある。**

## 通関手数料（gestión aduanera）の実額 ── 経路で 45 倍違う

| 経路 | 実額 | 出典の性質 |
|---|---|---|
| **自己申告**（correosaduanas.es で到着前に IVA を払う） | **€1.29 ＋ その 21% IVA €0.27 ＝ €1.56** | **支払画面の全文引用** |
| 同上（他の報告） | €1.50 / €1.60 / €2.25 | 複数一致 |
| Correos（払い損ねて配達時に現金） | **€6** | 複数一致 |
| Correos（別例） | €5 ＋ gastos suplidos €4.33 | 実請求 |
| Correos（別例） | €6.61 ＋ その 21% IVA ＋ suplidos €5.32 | 実請求 |
| Correos（€150 超・ADT 経由） | €20 前後 | 複数 |
| **FedEx（€150 未満）** | **€15** | 複数一致。courier では最安 |
| **FedEx（€150 超）** | **価額の 3%、最低 €15** | 実請求 |
| FedEx（書類のみ請求された例） | €70 | 1件 |
| **DHL** | **最低 €21 ＋ IVA、金額によらず** | 複数一致 |
| DHL（別例） | €25〜70 | 複数 |
| **UPS** | **関税額の 28.3%（€15.90）** | 第1次調査の1件 |
| courier 一般 | €15〜20 | 複数一致 |

**同じ国・同じ荷物でも、誰が通関するかで €1.56 〜 €70。45倍。**
現行コードは `clearanceFeePerParcel` を国ごとに1つしか持てない。

### 通関手数料に IVA がかかることが支払画面で確定

correosaduanas.es の支払明細（全文引用）:

```
Base Imponible:   €124.99
Total IVA:        €26.25
G Aduanera Base:  €1.29
  Cuota 21% IVA:  €0.27
  小計:           €1.56
Total Pagado:     €27.81
```

→ **「手数料 → その手数料への VAT」という二段構造。**第1次調査の UPS の1件と合わせて**3件で一致**。
現行モデルに費目が無い。

### 利用者の行動で費用が変わる

到着前に自分で払えば **€1.56**、放置して配達時に払うと **€6**。**約4倍。**
これは料金表ではなく**利用者の操作**で決まる。予測モデルは「どちらを想定するか」を明示しなければならない。

## EU €150 閾値の実務

| 事実 | 出典 |
|---|---|
| 閾値の判定は**商品価額のみ**（送料を含まない） | 複数一致 |
| ただし **IVA の課税ベースには送料を含む** | 複数一致 |
| €150 超で arancel（関税）。汎用コードで **2.5%**、報告では 2.5〜5% | 複数 |
| **為替で €148 → €151 になり閾値を跨いだ**実例 | 1件（本人が投稿） |
| **2件を分けて送れば閾値を回避できる**（FedEx 1個 €165 → Avia Small 2個に分割し €140/€70） | 1件 |
| ZenMarket は **IOSS で €150 未満の IVA を前払いでき、二重課税されたら返金する** | 複数 |

**為替で閾値を跨ぐ**のが決定的に重要。予測時点では税額が確定しない。
「€150 の 1円手前」を狙う利用者が実在し、その帯では点予測が原理的に不可能。

## 通関側が申告額を勝手に書き換える

| 実例 | 結果 |
|---|---|
| FedEx が **$58 を「58円」と誤読** | IVA が €0.07 になった |
| FedEx が実価値 €25 の品に **+€305 の「ajuste／valor estadístico €330」** | IVA €69 を請求 |
| Correos が €120 の NeoGeo CD を **€154 に引き上げ** | IVA＋gestión €45 |
| Correos が €40 の Saturn を **€54 に調整** | gestión €6 ＋ IVA €11 ＝ €17 |
| Correos の表示 €12.74 → 窓口で **€31.25** | 差 €18.51 |

**申告額の書き換えは実在し、しかも桁が変わる。**どんなモデルでも当てられない。
→ 区間予測でしか扱えない領域（`docs/TEST-PLAN.md` の区間＋カバレッジの根拠）。

## 【最重要】配送業者の選択が、会社の選択より効く

ZenMarket の見積、**同一荷物・スペイン向け**（利用者が投稿した比較）:

| 便 | 送料 |
|---|---:|
| 船便（ferry） | **€27** |
| FedEx | €40 |
| UPS | €55 |
| DHL | €61 |
| **EMS** | **€63** |

**送料だけで 2.3 倍。EMS は最も高い部類。**
さらに通関手数料が FedEx €15 / DHL €21〜 / Correos €1.56〜6 で乗るので、
**送料の安い DHL が通関で逆転する**という関係になる。

€27 と €63 の差は **€36 ≒ ¥5,900**（¥163/EUR）。
`docs/DESIGN-NOTES.md` が測った**会社間の最大差（5点で ¥5,250）と同等かそれ以上。**

→ **現行 proxycost は全社 EMS 固定で比較している。**
これは「最も高い便に全社を揃えて会社を比べている」ことになり、
**利用者にとっての本当の最安（船便 or FedEx）を1つも見せていない。**
会社の順位が正しくても、提示している総額は実際に選べる最安から大きく外れている。

## 追加で分かった探索の制約

- **Reddit は API トークン無しでは読めない。**`www.reddit.com` も `old.reddit.com` も
  検索 JSON が 403、reader 経由でも「network security によりブロック」。**未探索のまま。**

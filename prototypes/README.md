## 決まったこと

### 箱

- **前面だけ低い開口箱。**カメラは上・前・右から。中身が縁から覗く
- **箱を「埋める」表現にしない。** EMS は重量だけで決まり体積は価格に一切効かないので、
  満杯に見える箱は存在しない費用モデルを教えることになる
- **箱が大きくなるのは段を跨いだときだけ、離散的に。**連続的に膨らませない
- 推定重量の商品は半透明。**どれが総額の不確実さを生んでいるかが箱を見るだけで分かる**
- 弓（約2.2m）は箱から突き出て、150cm の赤い破線を越える。
  **いま実装は寸法を1バイトも見ていないので、送れないものに料金を出している。**
  それが絵で分かるのが、この可視化の一番の価値

### 動きの時間軸（追加1回 ≈ 1.6秒、直列）

```
落下 → 着地(410ms) 箱が沈む・重量の数字が回り始める
     → 段判定(970ms) 跨いだら赤いマーカーが1段85msで歩く
     → 送料・箱・判定文
     → 順位の行が滑って入れ替わる(+260ms)
```

**跨がなかった回は「+¥0」の灰色チップが出て、送料も箱も静止する。**
「何も起きなかった」ことを動きで言う。

### 形の語彙

**69個を一点物として描かない。**12家族 × 見分けるための差分で69個を覆う。
全部が違う形だと「これは薄いもの」「これは背が高いもの」という読み取りが効かなくなる。

家族は**店のカテゴリではなく「梱包される物として何か」**で切る。だからカテゴリを跨ぐ:

| 家族 | 数 | |
|---|---|---|
| Box | 8 | フィギュア7 + 箱入り腕時計 |
| Card | 3 | フォトカード・スリーブ入り単カード・鑑定済スラブ |
| Flat media | 7 | CD・LP・アルバム・DVD に写真集と雑誌を合流 |
| Bag | 7 | 高級鞄6 + 竹刀袋 |
| Footwear | 6 | スニーカー・足袋5 + 武道足袋 |
| Bottle | 4 | 調味料・300/720/1800ml |
| Packet | 5 | 菓子・茶・麺・ソフトベイト・小物袋 |
| Blister card | 6 | 釣り小物。ブリスターの中身だけが変わる |
| Reel | 4 | 不明・スピニング・ベイト・電動 |
| Long | 9 | ライトスティック・木刀・竹刀・居合刀・弓・竿4 |
| Folded garment | 5 | 帯・袴・胴着・上下 |
| Bogu | 5 | **ここだけシルエットではなく藍と漆の材質言語で括っている** |

差分の軸: 比率・高さ・厚み・面の分割（窓・帯・背・ラベル）・持ち手・角の丸み。
**新しい形を足すのではなく、家族の中で振る。**

**種類が不明な品（`reel` / `rod`）は、家族のシルエットから決め手を剥ぎ取って点線で描く。**
「不明」を別の品ではなく状態として見せる。確度4段階（`—` / 点線 / `~` / 確定）と同じ思想。

- 箱と語彙の実装形式が違う。箱は CSS 3D の押し出し、語彙は平面 SVG。
  流し込むときは `.thing` の div を `renderGlyph(id)` に差し替える形になる

## 保留（別途）

- **寸法を持つか。**タイトルからの抽出は実測で50件中2件（4%）しか取れず、うち1件は誤り
  （「柄長さ30cm」を全長と読んだ。竹刀は実際 約120cm）。
  ただし**規格が長さを決めている品**はある（竹刀39 = 三尺九寸 ≒ 120cm、弓の並寸 = 221cm）。
  重量表と同じ構造で「品種の規格寸法」なら一次情報から取れる可能性がある
- **Buyee の既定を `consolidated` にする。**同梱は無料（原文で確認）で申請すれば効くのに、
  既定で注文ごとに分ける側を順位に出しているのは実態から遠い。
  同じ6商品で ¥93,026 → ¥65,911（**¥27,115 差**）

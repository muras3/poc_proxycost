# proxy-cost-jp

日本の購入代行 3 社（Neokyo / ZenMarket / Buyee）の**総額**を、買う前に並べて比較する。

## なぜ作るか

海外の買い手の不満は「手数料が高い」ではなく「**買い終わるまで総額が確定しない**」。
Trustpilot の Buyee 低評価（8,057 件・3.6★）でも、二重請求・保険の重複・送料見積りのブレが主軸になっている。

そして各社は**料金の掛け方の構造が違う**ので、点数と国内送料の有無で最安が入れ替わる。
静的な比較記事では答えが出せない。実際、r/AnimeFigures では
「どの代行を使えばいい？」が 2020 年から 1〜2 ヶ月おきに再発し続けている。

## 実測（商品 ¥3,000 × N、国内送料 ¥500/件、国際送料込み）

| 点数 | 最安との差 |
|---:|---:|
| 1 | ¥686 |
| 3 | ¥2,950 |
| 5 | ¥5,250 |
| 10 | ¥11,000 |

**1 点では意味が無く、3 点以上で効く。**客はまとめ買いする層。

## 料金は一次情報のみ

比較記事（二次情報）は実際に 3 項目とも外していた。

| 項目 | 二次情報 | 公式 |
|---|---|---|
| ZenMarket 手数料 | 「¥300 一律」 | **¥300〜800 / 1 点ごと** |
| ZenMarket 入金手数料 | 「1%」 | **3.5%**（送金合計額ベース＝実質 3.63%） |
| ZenMarket 国内送料 | 「込み」 | **別途**（送料無料の商品もある） |

出典は `src/fees.js` に URL 付きで書いてある。**ここが間違っていたらツールの価値はゼロなので、
一次情報以外は入れない。**

## 構成

```

src/calc.js        3 社の総額と内訳

```

## 正直に書いていること

国内送料と国際送料は**利用者の入力**。中古の出品ページに重量はほぼ書かれておらず、
梱包するまで誰にも確定できない。UI 上でもその 2 行だけ色を変えて見積りだと明示している。
それ以外は公開されている料金表をそのまま全額適用している。
